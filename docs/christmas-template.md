# 圣诞模板

Web 模板选择器中的「圣诞款 · A5 竖版」，模板 ID 为 `圣诞.png`。
默认内容尺寸 144 × 210 mm；底部编号启用时沿用编辑器额外增加 3 mm 的规则。

- 底图由用户提供的圣诞图案表组成，源图为 1748 × 2480 像素；每排先水平居中，再整体缩小 5% 并输出到 1701 × 2480 像素的 144 × 210 mm 画布。
- 共 7 排、38 个照片位置，每排数量依次为 4、4、6、6、6、6、6。
- 图案按矩形安全区域放置照片，照片、图案和位置同步缩放；支持多选、循环填图、移动、缩放、裁剪、PNG 导出与共享作品保存。
- 计入透明抗锯齿边缘时，各排左右留白约为 8.55、8.38、7.62、8.04、7.37、5.16、7.62 mm，全部超过 5 mm。

底图文件为 `web/public/embedded/heart-star/assets/christmas-template.png`，模板定义在 `christmas-template.js`。
