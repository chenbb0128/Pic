# 人像补光

在 Web 爱心星星编辑器右侧「头像微调 → 人像补光」中使用。

- 先上传并选中头像，点击「一键补光」自动使用 100% 强度。
- 强度可在 0–200% 之间调整；0% 或「恢复原亮度」取消补光。
- 多选时只处理选中位置；不同照片分别分析亮度，相同照片复用计算结果。
- 恢复原亮度保留已完成的去底、裁剪和位置调整。替换为新照片时清除该位置原有的补光参数。
- 缩略图、大图预览、画板、PNG 和保存的作品成品使用相同效果。

补光在浏览器本地完成，通过可见像素的亮度分布选择提亮曲线，保护深黑和高光并尽量保持颜色比例；PNG 透明度和照片像素尺寸不变。处理对象为上传的整张照片，不进行面部识别，照片未去底时其背景也会随照片一起处理。

照片原始像素与补光参数分开保存。`states[].photoLight` 表示 0–200 的补光强度，照片层仍保留补光前的图片；反复调节从该图片重新计算，不叠加变白。作品快照保留参数，重新打开后可继续调整和恢复原亮度；存为模板仍不包含客户照片。

大图处理会分批让出浏览器主线程。批量处理全部成功后才更新参数；过程中换图、切换模板或再次拖动强度时，过期结果不会覆盖当前内容。处理期间等待补光完成后再预览、导出或保存。

浏览器验证：`node scripts/smoke-photo-lighting.cjs`。沿用项目现有的 `PIC_PLAYWRIGHT_PATH`、`PIC_BROWSER_PATH` 配置；设置 `PIC_LIGHTING_PREVIEW_DIR` 可保存测试示意图的前后对比、编辑器截图和实际导出的 PNG。测试使用生成的示意头像及本地快照编解码，不上传照片或调用 AI 服务。
