# 草莓模板

Web 模板选择器中的「草莓款 · A5 竖版」，模板 ID 为 `草莓.png`。
默认内容尺寸 148 × 210 mm；底部编号启用时沿用编辑器额外增加 3 mm 的规则。

- 画布为 1748 × 2480 像素，使用用户提供的图案；各排整体水平居中，图案大小及排内间距保持原样。
- 7 排、36 个照片位置，每排数量依次为 4、4、6、6、6、5、5。
- 当前使用用户提供的无头像底图，已替换临时示例图；未上传照片时仅显示图案。
- 照片中心按无头像底图的填实轮廓重新标定，排除纹理中的透明孔洞；爱心、草莓及蛋糕按主体面积中心居中。照片大小保持原有设置，支持多选、循环填图、移动、缩放、裁剪、PNG 导出与共享作品保存。
- 每排左右留白相等；默认 148 mm 宽、计入透明抗锯齿边缘时，从上到下每侧约为 7.11、7.62、5.42、5.50、5.50、8.97、8.64 mm。照片及选区与底图使用相同的水平平移。
- 这张完整底图暂未拆分为可互换的图案素材。

## 后续更新底图

1. 新底图须按排居中后再替换到
   `web/public/embedded/heart-star/assets/strawberry-template.png`，画布仍为 1748 × 2480。
   当前各排相对用户原图的水平平移（像素）为 `19、19、9、2.5、2.5、-7.5、-0.5`；
   整数平移直接复制像素，半像素平移用预乘透明度插值，保留图案比例及透明边缘。
2. 在 `strawberry-template.js` 中递增 `source` 的 `?v=` 版本（当前为 `v=3`），
   同时递增 `index.html` 中该脚本的版本，确保浏览器加载更新后的资源。
3. 照片及图案的原始位置位于 `strawberry-template.js` 的 `rows` 中，
   `rowOffsets` 与底图各排的水平平移一致；更新底图时同步校准二者。

共享作品会保存自己的底图与位置快照，更新内置底图不会改变旧作品。
本地接入不等于线上发布，线上使用需按现有 Web 发布流程部署。
