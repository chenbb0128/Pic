# 草莓模板

Web 模板选择器中的「草莓款 · A5 竖版」，模板 ID 为 `草莓.png`。
默认内容尺寸 148 × 210 mm；底部编号启用时沿用编辑器额外增加 3 mm 的规则。

- 原图为 1748 × 2480 像素，完整保留用户提供的 PNG。
- 7 排、36 个照片位置，每排数量依次为 4、4、6、6、6、5、5。
- 当前使用用户提供的无头像底图，已替换临时示例图；未上传照片时仅显示图案。
- 沿用已标定的照片位置；支持原有多选、循环填图、移动、缩放、裁剪、PNG 导出与共享作品保存。
- 这张完整底图暂未拆分为可互换的图案素材。

## 后续更新底图

1. 将同版、同画布（1748 × 2480）的无头像 PNG 替换到
   `web/public/embedded/heart-star/assets/strawberry-template.png`。
2. 在 `strawberry-template.js` 中递增 `source` 的 `?v=` 版本（当前为 `v=2`），
   同时递增 `index.html` 中该脚本的版本，确保浏览器加载更新后的资源。
3. 照片及图案位置均位于 `strawberry-template.js` 的 `rows` 中。
   同尺寸、同位置的底图可直接复用；画布或版式变化时重新标定。

共享作品会保存自己的底图与位置快照，更新内置底图不会改变旧作品。
本地接入不等于线上发布，线上使用需按现有 Web 发布流程部署。
