# 共享排版保存与查找体验实施计划

> 按 executing-plans 在当前会话逐项执行；沿用已有 codex/shared-backend 分支，不 commit、push 或部署。

**目标：** 让门店成员知道是否已保存，并能凭缩略图、名称和编号找到共享排版。

**方案：** 前端轻量快照指纹区分编辑与仅选择；保存成功或打开后建立基线，失败不清除修改状态。iframe 提供同源状态查询供 Vue 路由离开检查；原生 beforeunload 保护刷新关页。私有缩略图复用现有图片接口，模板预览不渲染照片；MySQL 保存缩略图引用和编号，列表支持服务端关键词过滤。

## 约束

- 不引入新依赖，不改变原排版和正式 PNG 导出，不自动保存或覆盖共享文件。
- 沿用共享鉴权、version 乐观锁、原图私有存储和软删除。
- 旧项目没有缩略图时显示占位，仍可正常打开。
- 本地草稿、回收站、历史版本、生产部署不在本轮范围。
