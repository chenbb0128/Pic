# 门店共享模板与排版项目

## Goal

使用 chenbb0128/go-template 作为 server/ 基座，增加单门店共享登录、私有图片、模板和项目保存。第一期接通爱心星星编辑器，不改变原有本地图片处理与导出。

## Architecture / Constraints

- web/ 保持现有 Vite/Vue 和嵌入编辑器；根 Dockerfile 保持现有静态发布。
- server/ 导入上游固定提交 645298854f626b31e565a93c03ba6602cc3be2fc，使用原有 Gin、MySQL、Goose。Redis/Worker 暂不启用。
- 单门店内共享读写，不做个人隔离或实时协同；登录只保护云端数据接口，不改变原有工具入口。
- 会话使用 HttpOnly cookie，写接口验证同源请求；凭证从环境配置，不在仓库写生产密码。
- 图片仅允许经鉴权访问；数据库保存不透明文件 ID，磁盘保存随机文件名，不保存 blob URL。
- 模板不带客户照片；项目保留模板快照和全部照片、背景、参数。JSON schemaVersion 明确版本。
- 文档更新使用 version 条件更新，冲突返回 409，不静默覆盖。
- 数据库和原文件独立持久化，发布不清理。第一期不做删除文件、历史版本或自动清理，避免破坏旧项目。
- 不新增前端依赖，不迁移旧模板资产；不 push、不部署。

## Tasks

1. 导入后端基座；新增根 README、目录说明、本地 Compose、环境示例，保留上游来源。
2. TDD：登录/会话、私有资产校验和访问、共享文档 CRUD/乐观锁/快照与引用校验；数据库迁移和 API 装配。
3. TDD：编辑器快照序列化（图像转文件引用、模板剥离客户照片）、恢复与版本冲突 API 客户端。
4. 爱心星星新增云端保存、另存为模板、共享列表与打开；服务未启动时不影响原本本地编辑。
5. 增量验证：新增 Go 业务测试、数据库集成测试（有环境时）、新增前端测试和相关类型检查；文档记录实际运行结果和未验证事项。

## Verification

- 未登录不能读取文件、模板或项目；错误凭据不能创建会话；写操作拒绝外站 Origin。
- 图片类型、大小、随机路径；原文件可重新读取；项目只引用存在的本门店文件。
- 两人持有同一 version 时仅一人更新成功；项目快照不随模板变化；列表不带客户图片数据。
- 保存/打开后恢复照片、替换背景、位移缩放、图案、编号、DPI；模板不包含客户照片。
- 只运行这些功能直接相关的最小测试，不进行全项目回归。

## 本地实施与验证结果（2026-10-23）

- 已导入固定版本基座，新增共享业务模块、迁移、私有文件存储、开发启动脚本和前端入口；现有发布链未改，不 commit／push／部署。
- 专用 MySQL 已启动于 127.0.0.1:3307；业务库 pic、测试库 pic_test，与旧数据库隔离。宿主 Go API 运行于 127.0.0.1:8081，Vite 5173 代理已接通。
- 后端业务、MySQL 持久化／并发版本控制、数据库时区、路由挂载的增量测试通过；API／migrate 编译通过。
- 7 个直接相关前端测试文件、70 项测试通过；vue-tsc 类型检查通过。
- 浏览器实际上传照片和背景，默认爱心、横版、混合、自定义、文案五类模板均通过登录、项目保存、模板剥离照片、整页刷新、会话保留、重新打开检查。恢复参数和解码原图像素完全相同，合成预览允许 Chromium 边缘抗锯齿误差（单通道不超过 12/255，变化像素不超过 2%）。
- 修复检查发现的问题：入口藏在旧版隐藏标题栏；已释放的背景 blob URL 导致共享上传失败；自定义恢复后重排误用旧目录；成功登录消耗失败限流额度；MySQL JSON 归一化改写浮点坐标。新增迁移将快照改为 LONGTEXT + JSON_VALID 校验，新增真实 MySQL 原文精度回归测试。
- Docker Compose 配置校验通过；未构建后端 Docker 镜像，未验证生产 HTTPS／NAS 反代和备份恢复，也未接入自动排版页面。这些不属于本轮本地 MVP。
- 数据保留：文档软删除；照片不自动清理。浏览器测试自己的文档已软删除，原始测试图按同样策略留存，不会删除客户文件。
