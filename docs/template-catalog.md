## 容易混淆的对应

- A05 当前对应草莓甜心。旧订单保存为 `A05` 时沿用历史蓝色款；新订单使用 `草莓.png`，两者不能直接批量替换。
- A07 对应自定义排版的逐排组合。此前关联的 `甜心派对.png` 已纠正；历史订单如已保存该模板 ID，仍指向甜心派对，不会仅凭新编号映射自动变为 A07。
- A11 的商品名是「焦糖秋枫混合豹纹」，编辑器中的名称是「经典豹纹款 · 爱心＋星星」。
- A12 的商品名是「奶油黑粉混合豹纹」，编辑器与模板 ID 中的词序为「黑粉奶油」。

## 说明项与无编号模板

商品后台中的「记得发图片给客服不清楚的可以看」「发送图片给客服一张一个照片」是客服提示项，不分配 A 编号，也不关联制作模板。

以下编辑器选项目前没有对应的正式 A 编号，保留名称，不占用或复用现有编号：甜心派对、蓝色款、豹纹星星款、波点爱心款、波点圆形款、文案款。

## 维护与检查

- A 编号、商品规格名和模板 ID 的代码映射统一维护在 `vagaga/src-tauri/assets/templates.json`；调整时同步更新本表。
- 显示名称可以带 A 编号，模板 ID 继续作为订单、链接及保存文件中的关联键。
- 网页端与 PC 内置编辑器均应能找到表中的模板 ID。执行 `node vagaga/tool/sync_templates.mjs` 可检查两端选项是否齐全；该命令不检查商品缩略图是否对应，变更模板图时仍需对照商品规格图核验。
