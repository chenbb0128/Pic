# 网页字体来源与许可

本站姓名排版、文字方格使用的 12 款字体均随附各自的 SIL Open Font License 1.1。
许可允许在遵守条款、保留版权及许可声明的前提下进行商用、嵌入和再分发；不能将字体单独出售。
用户生成的 PNG 不受字体软件的 OFL 许可约束。

字体从官方仓库原样下载，未修改字形。`Caveat.ttf` 仅将上游文件名中的 `[wght]` 去除。
下载日期：2026-10-16。每个字体旁的 `字体文件名.OFL.txt` 保留完整版权和许可文本。
原始下载地址及许可证来源见 [SOURCES.json](./SOURCES.json)。

| 风格 | 字体 |
| --- | --- |
| 可爱、圆润 | 站酷快乐体、站酷庆科黄油体、霞鹜漫黑 |
| 手写、文艺 | 霞鹜文楷（Lite 字库）、站酷小薇体 |
| 毛笔、草书 | 马善政楷书、龙藏体、刘建毛草、志莽行书 |
| 英文手写、花体 | Patrick Hand、Caveat、Pacifico |

字体通过 FontFace API 在选择时从本站加载，不访问第三方字体服务，不会预加载全部字库。
英文专用字体不提供中文字形；中文字体也可能缺少个别生僻字，缺字时由浏览器使用系统字体补全。
